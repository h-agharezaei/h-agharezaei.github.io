# Blog project notes

Hugo + PaperMod bilingual blog (fa primary, en). Before writing or editing any post, read in this order:

1. [CONTENT_STYLE_GUIDE.md](CONTENT_STYLE_GUIDE.md): voice, tone, editorial check.
2. [WRITING-GUIDE.md](WRITING-GUIDE.md): front matter, length, glossary, demos, truthfulness, build.
3. [ROADMAP.md](ROADMAP.md): calendar, series, titles.

Reviewing an existing post: follow section 9 of the style guide. Report problems with concrete examples first, and do not rewrite until asked. Never add personal experiences the author has not provided.
