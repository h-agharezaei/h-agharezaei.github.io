EIP-7702, added in Ethereum's Pectra upgrade in 2025, lets an ordinary wallet (an externally owned account) sign an authorization that delegates its code to a smart contract. From then on, calls to the wallet run that contract's code until the wallet signs a new authorization. An authorization is valid only at the wallet's current nonce. For a [hot wallet](/glossary/hot-wallet/), an unexpected delegation means someone else may now control it, so signers should refuse authorizations they do not expect.
