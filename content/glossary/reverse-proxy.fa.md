reverse proxy اتصال HTTP کلاینت را تمام می‌کند، درخواست را می‌خواند و درخواست تازه‌ای به backend می‌فرستد. چون HTTP را می‌فهمد می‌تواند بر اساس path مسیریابی کند، هدر اضافه کند و دوباره تلاش کند.
